# Security policy

Report security problems in flitz privately through GitHub's private vulnerability reporting: open the [Security tab of michaelwolz/flitz](https://github.com/michaelwolz/flitz/security) and choose "Report a vulnerability". Don't open a public issue or pull request for them. If you can't use GitHub's reporting, email michaelwolz93@gmail.com instead.

Include what you found, how to reproduce it, and the version or commit you tested. You can follow the report and its fix in the advisory. Only the latest release gets security fixes: upgrade before you report, and expect the fix as a new release, not a backport.

A short URL that leads to phishing or malware is not a security problem in flitz: report it to whoever runs the instance that serves it.
